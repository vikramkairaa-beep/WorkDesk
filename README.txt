NOVA WORKDESK — FRESH START + DATE RANGE EOD REPORT

FILES
- index.html: app layout
- styles.css: responsive design
- app.js: tasks, local browser storage, date-range EOD report
- README.txt: setup instructions

RUN
1. Extract this ZIP.
2. Open VS Code > File > Open Folder > select NovaWorkDesk.
3. Install the Live Server extension if needed.
4. Right-click index.html > Open with Live Server.

DATE-WISE WORKFLOW
1. Office Tasks > add a task.
2. Set Task From Date and Task To Date (for example 12-01-2026 to 14-01-2026) and add notes such as "Verified 284 IDs".
3. Open EOD Report.
4. Select From date and To date (for example 07-10-2026 to 08-10-2026).
5. Generate report. It includes each task's date range and notes when the task range overlaps the selected report range.
6. Click Copy report.

Tasks start empty. Data is saved only in this browser on this device. This is a web app prototype, not a native Android APK.
